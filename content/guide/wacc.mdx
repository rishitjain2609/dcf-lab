## Worked example

**Cost of equity (CAPM)**

```
costOfEquity = riskFreeRate + beta × equityRiskPremium
             = 7% + 1.0 × 6%
             = 13%
```

**WACC**

| Input | Value |
| --- | --- |
| Market cap (equity weight) | ₹1,800 cr |
| Total debt (debt weight) | ₹200 cr |
| Cost of equity | 13% |
| Cost of debt | 8% |
| Tax rate | 25% |

```
weightOfEquity = 1,800 / (1,800 + 200) = 90%
weightOfDebt   = 200 / (1,800 + 200)   = 10%
afterTaxCostOfDebt = 8% × (1 - 25%) = 6%

WACC = 13% × 90% + 6% × 10%
     = 12.3%
```

Computed by `wacc()` in [`/lib/dcf.ts`](https://github.com/rishitjain2609/dcf-lab/blob/main/lib/dcf.ts).
