## Worked example

Implied value per share (end-year discounting), varying WACC by ±1 percentage point and terminal
growth by ±0.5 percentage points around the base case (WACC 12.3%, terminal growth 4.0%):

| WACC ↓ / g → | 3.5% | 4.0% | 4.5% |
| --- | --- | --- | --- |
| 11.3% | ₹35.49 | ₹37.64 | ₹40.11 |
| 12.3% (base) | ₹30.74 | **₹32.36** | ₹34.19 |
| 13.3% | ₹26.97 | ₹28.22 | ₹29.62 |

A 2-point swing in WACC (11.3% → 13.3%, holding terminal growth at 4.0%) moves the implied value
from ₹37.64 to ₹28.22 — about ₹9.4/share, or roughly 29% of the base case — without changing a
single operating assumption. That sensitivity is the real output of a DCF, not the single number
in the middle.

Built with `buildSensitivityTable()` in
[`/lib/dcf.ts`](https://github.com/rishitjain2609/dcf-lab/blob/main/lib/dcf.ts), which takes a
list of row values, a list of column values, and a function to compute each cell — reused as-is
for the [models](/models) and the [game](/game).
