## Worked example

Using the end-year enterprise value from [Discounting (mid-year)](/guide/discounting-mid-year) —
₹439.12 cr of explicit FCFs plus ₹1,055.38 cr of discounted terminal value:

| Step | ₹ cr |
| --- | --- |
| Enterprise value | 1,494.50 |
| − Net debt | 200.00 |
| **Equity value** | **1,294.50** |
| ÷ Diluted shares (cr) | 40 |
| **Implied value per share** | **₹32.36** |

```
equityValue = enterpriseValue - netDebt - minorityInterest + investments
impliedValuePerShare = equityValue / dilutedShares
```

Using the mid-year enterprise value instead (₹1,583.75 cr) gives an implied value per share of
₹34.59 — a reminder that the discounting convention alone can move the answer by a few percent.

`enterpriseToEquityValue()` and `impliedSharePrice()` in
[`/lib/dcf.ts`](https://github.com/rishitjain2609/dcf-lab/blob/main/lib/dcf.ts).

Never call this a "target price" — see the [disclaimer](/about). It's an implied value under one
set of assumptions, not a prediction.
